Applies to: all engines; all production periods

When the central locking is operated using either the key or the remote control or from the inside using the safety knob, one of the front doors does not close properly.

If one door does not close properly, all four doors may close and then re-open after a few moments when the door lock is operated.

Results of the tests

1

CHECK DOOR LOCK STRIKER

All OK

Problems met

Operation

Check that the lock striker is fixed correctly

Continue to Step 2

Striker incorrectly secured

Refix the striker correctly Op. 7005A10 front side door - adjust striker and adapt seal in necessary

KEY OPERATION CHECK

All OK

Problems met

Operation

Check that the door opens / closes properly using the key

Faults in the control rods

Re-engage the linkages correctly on the external handle and lock Op. 7005C43 link connecting front side door barrels/catch - r+r

Lock not fixed correctly

Refit the lock correctly on the door Op. 7005N21 front side door lock motor-lock assembley-r r

CHECK KNOB OPERATION
