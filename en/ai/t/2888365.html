Applies to: all engines; all production periods

Whilst steering, the steering is irregular or does not respond to the action of the steering wheel

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

First check the tyre inflation pressures

Visually inspect the power assisted steering fluid level in the reservoir

Continue to Step 1

Pressure not correct

Restore the tyre inflation pressures

Power assisted steering fluid level too low

Restore the correct level, if there are leaks,

See table X30 POWER ASSISTED STEERING SYSTEM FLUID LEAKS

1

FRONT WHEEL GEOMETRY CHECK

All OK

Problems met

Operation

Check the front wheel geometry and angles, Op. 4450A10 front wheel geometry - check using optical equipment - includes front wheel tow-in adjustment if necessary

Continue to Step 2

Geometry not correct

Check and, if necessary, replace the damper Op. 4410A12 front suspension damper (one), lh or rh - for mcpherson strut system - includes dismantling/re-building of assembly at bench r r

Angles not correct

Restore, where possible, the correct angles

2

CHECK REAR WHEEL GEOMETRY

All OK

Problems met

Operation

Check the rear wheel geometry and angles Op. 4450A40 rear wheel geometry - check using optical equipment

Continue to Step 3

Geometry not correct

Check and, if necessary, replace the damper Op. 4420A30 l/h or r/h rear suspension damper (one) - r+r

Geometry not correct

Check and, if necessary, replace the spring Op. 4420A48 rear suspension coil springs- r r

Angles not correct

Restore, where possible, the correct angles

3

STEERING BOX CHECK

All OK

Problems met

Operation

Check that the steering box is working properly: there should not be excessive "power assistance"

Continue to Step 4

Steering box not properly calibrated

Replace the steering box Op. 4130A10 power steering box - r+r - check tow-in if necessary separately - includes bleeding

4

CHECK ON CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists
