Applies to: all engines; all production periods

The rear fog lamp does not work when the switch on the control panel in the centre of the facia is operated with the dipped beams on (or fog lamp on)

Results of the tests

1

CHECK LIGHT

All OK

Problems met

Operation

Check the bulb and the bulb holder unit

Continue to Step 2

Bulb damaged

Change bulb

Bulb holder faulty

Repair or change the left tail-light Op. 5540A44 L/H OR R/H TAIL LIGHT (ONE) - R+R

2

CHECK REAR FOG LAMP ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • rear fog lamp fuse
  • control panel supply fuse
  • control panel power supply
  • connections between junction unit and control panel
  • connections between control panel and bulb
  • control panel earth
  • bulb earth

( See E2031 REAR FOG LAMPS).

Continue to Step 3

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections

3

CHECK REAR FOG LAMP SWITCH

All OK

Problems met

Operation

Check operation of the rear fog lamp switch located on the control panel in the middle of the facia ( See E2031 REAR FOG LAMPS).

( See E2031 REAR FOG LAMPS).

the actual switch is built into a electriconic control device that manages the rear fog lamp operating cycle.

Continue to Step 4

Rear fog lamp switch faulty

Repair the rear fog lamp switch or change the control panel Op. 7065C10 air conditioning control panel - r+r

4

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
