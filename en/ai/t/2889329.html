Description

The CONNECT system is available on request: it is a Bosch RADIOPHONE radio personalized especially for the FIAT MULTIPLA and includes the CONNECT device.

For more details 5580N intergrated control system (ics) panel .

This system includes:

  • GSM module and SIM-CARD reader integrated in the radio-telephone-navigator;
  • hands-free function via the radio speakers;
  • microphone located in the front courtesy light;
  • outside aerial.

Full details of the specifications and the operation of the RADIOPHONE are given in the 'OWNER'S HANDBOOK'.

The commands of the telephone function are grouped together on a conventional telephone keyboard (12 buttons), with in addition dedicated keys for emergency calls.

On versions with steering wheel radio controls the commands for the telephone function can also be sent.

The aerial is fitted in the front part of the roof. It is dual function (GSM/radio). E3510 RADIO
