Applies to: all engines; all production periods

During starting, the "ABS" warning light does not come on (it should come on for 4 seconds to indicate that the initial control unit test is being carried out and then it should go out)

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check that there is a regular dialogue with the ABS control unit

Continue to Step 2

Lack of dialogue with the control unit

Restore:

  • the connection between the ABS control unit and the diagnostic connector
  • the supply for the ABS control unit ( See E7020 ABS ).

An error is detected in the control unit

Continue according to the instructions for the diagnostic equipment

2

CHECK INSTRUMENT

All OK

Problems met

Operation

Check the condition of the ABS warning light., located in the instrument see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

The warning lights consist of LEDs built into the electronic circuit, and so CANNOT be replaced.

Continue to Step 3

Instrument not working

Change the instrument Op. 5560B10 analogue control panel - r+r

3

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
