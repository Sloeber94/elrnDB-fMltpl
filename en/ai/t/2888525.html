EURO 3 VERSIONS

FUEL CONSUMPTION AS PER DIRECTIVE 1999/100/CE (Litres x 100) Km)

The consumption values given in the table have been determined in accordance with the fuel consumption measurement requirements stipulated in Directive 99/110/CE.

Valid for all versions

These values have been defined during homologation tests.

The specified test conditions are:

  • one urban cycle, which includes one cold start, followed by a simulated varied urban journey;
  • one non-urban cycle, which includes frequent accelerations, in all gears, simulating normal non-urban use of the vehicle. The speed varies between 0 and 120 km/h.
  • The average combined consumption comprises 37% urban cycle and 63% non-urban cycle.
