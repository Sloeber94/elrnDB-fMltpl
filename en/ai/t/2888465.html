Applies to: all engines; all production periods

The climate control works properly, but there is too much noise coming from the engine compartment

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Disconnect the services belt and check whether the noise disappears.

Do not let the engine run for long with the belt disconnected

Check whether the noise only occurs with the engine switched off

Continue to Step 1

The noise disappears with the services belt disconnected

See table S10 ENGINE WHILSTLING / SERVICES BELT NOISY'

The noise only occurs with the engine switched off, check that it is not coming from the fan

See table S59 ENGINE FAN NOISE'

1

PIPES AND COMPONENTS FIXING CHECK

All OK

Problems met

Operation

Check that the system pipes and components are correctly fixed. In the order:

  • drier filter fixing
  • pipes fixing (with bands and spacers)
  • no interference between the pipes and other components in the engine compartment

Continue to Step 2

Components fixing not correct

Restore the correct tightening.

If necessary, replace the bands or spacers, (see Assembly 5040A)

Interference in the engine compartment

Restore the correct layout, (see Assembly 5040A).

2

COMPRESSOR FIXINGS CHECK

All OK

Problems met

Operation

Check that the compressor is correctly fixed to the engine

Continue to Step 3

Compessor fixing not correct

Tighten the bolt to the specified torque. Op. 5040A20 air conditioner compressor - r+r - includes fluid level check and top up if necessary

3

COMPRESSOR CHECK

All OK

Problems met

Operation

Check that the noise is not coming from inside the compressor

If this is the case, it is accompanied by a system malfunction. See table L01 CLIMATE CONTROL NOT WORKING / UNDER NO CIRCUMSTANCES

Continue to Step 4

Compressor malfunction

Replace the compressor Op. 5040A20 air conditioner compressor - r+r - includes fluid level check and top up if necessary

4

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists
