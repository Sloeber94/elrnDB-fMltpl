J04 BACK WINDOW WIPER NOT WORKING

Applies to: all engines; all production periods

With the ignition key in the ON position, when the lever on the right of the steering wheel is operated, the rearscreen wiper does not work properly., but the rearscreen washer does work

Results of the tests

1

REARSCREEN WIPER MOTOR SUPPLY CHECK

All OK

Problems met

Operation

Check, in order:

  • motor connection to earth
  • connection between motor and steering column switch unit See E3021 REAR WINDOW WASH/WIPE

Continue to Step 2

Connection broken

Restore the connections

2

REARSCREEN WIPER MOTOR CHECK

All OK

Problems met

Operation

Check that the windscreen wiper motor is working properly and, in particular, the electronic device inside it

Continue to Step 3

Motor electronic device faulty

Replace the electronic device Op. 5050C45 rear motor wiper intermittent function - r r

Motor faulty

Replace the windscreen wiper motor Op. 5050C42 rear wiper motor - r+r

3

STEERING COLUMN SWITCH UNIT CHECK

All OK

Problems met

Operation

Check that the steering column switch unit is working properly: in particular, the rearscreen wiper switch:see DESCRIPTION AND OPERATION: 5050 SCREEN WASHERS AND HEADLAMP WASH/WIPE

Continue to Step 4

Stalk unit not working properly

Replace the steering column switch unit Op. 5550A12 complete stalk unit - r+r for versions with air bag

4

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists
