Applies to: engines: 1.6 16v; all production periods

The engine is not running smoothly when idling; in particular, it does not maintain a constant, regular value as the load varies (e.g. when electrical devices are switched on, etc.).

Applies to: engines: 1.6 16v; all production periods; only with equipment: BIPOWER

The engine idles unevenly; in particular, the level is not consistent and regular when the load is altered (e.g. consumers switched on, etc.).

NOTE: After system components have been replaced the self-adjustment parameters must be zeroed in order to restore the values originally set in the factory to the control unit maps

Applies to: engines: 1.6 16v; all production periods; only with equipment: BIPOWER
