Applies to: all engines; all production periods

The reading on the special instrument in the panel shows a high engine coolant temperature

The cooling fan comes on normally (Otherwise D31 ENGINE OVERHEATING / WITH FAN NOT WORKING).

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Preliminarily check:

  • engine coolant level
  • radiator cleanliness and condition
  • condition of the expansion tank, and particularly the cap seal

Continue to Step 1

Insufficient engine coolant level

Top up the engine coolant level If the defect persists,

See table X10 ENGINE COOLANT LEAKS

Cap faulty

Replace the component (see Assembly 1048A)

Air intake circuit component damaged

Repair or replace the cap (Op. 1088A10)

Radiator dirty, damaged or deformed

Clean the radiator. If necessary, replace it Op. 1088B24

1

TEMPERATURE GAUGE OPERATION CHECK

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket (in the engine management control unit ambient): read the engine temperature value shown amongst the parameters and compare it with the instrument reading

Continue to Step 2

Values do not agree, instrument reading faulty

See table K26 ENGINE COOLANT OVERHEATING WARNING LIGHT NOT WORKING

2

CHECK COOLANT TEMPERATURE SENSOR

All OK

Problems met

Operation

1.6 16v

Check that the engine coolant temperature sensor is working: See Test 1056C Checking engine coolant temperature sensor operation

Continue to Step 3

Sensor faulty

Replace temperature sensor Op. 1056B50 coolant temperature sensor - r + r

Connections not correct

Restore the connections ( See E4010 INSTRUMENT PANEL)

1.9 JTD 8V

Check that the engine coolant temperature sensor is working: See Test 1060E Checking engine coolant temperature sensor operation

Continue to Step 3

Sensor faulty

Replace temperature sensor Op. 1060G14 engine coolant temperature sensor - r r

Connections not correct

Restore the connections ( See E4010 INSTRUMENT PANEL

3

CHECK THERMOSTAT UNIT

All OK

Problems met

Operation

Check

  • the condition of the thermostat unit
  • that it is correctly calibrated

Continue to Step 4

Thermostat unit faulty

Bleed the system, replace the thermostat unit if the anomaly persists Op. 1088C40 thermostat- r + r

4

WATER PUMP CHECK

All OK

Problems met

Operation

Check

  • the condition of the water pump
  • the seal of the gaskets

Continue to Step 5

Water pump faulty

Replace the water pump or the gaskets Op. 1088C12 water pump - r+r for versions with air conditioner

5

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present
