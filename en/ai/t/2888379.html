Applies to: all engines; all production periods

When the knob on the dashboard is operated, with the dipped beam headlamps on, the headlamp adjustment function does not work.

Results of the tests

1

CHECK HEADLAMP ADJUSTMENT MOTOR

All OK

Problems met

Operation

Check that the headlamp adjustment motor is working properly

Continue to Step 2

Motor damaged

Replace headlamp adjustment motor Op. 5540C24 MOTOR (ONE) FOR L/H OR R/H HEADLAMP/LIGHT CLUSTER ALIGNMENT CORRECTION - R+R

2

CHECK HEADLAMP ADJUSTMENT CONTROL

All OK

Problems met

Operation

Check that the headlamp adjuster is working

( See E3080 HEADLAMP AGLINMENT CORRECTOR).

Continue to Step 3

Headlamp adjuster faulty

Repair or replace the headlamp adjuster Op. 5540C18 headlamp/light cluster alignment correction motor switch - r+r

3

CHECK HEADLAMP ADJUSTER ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • connection between junction unit and headlamp adjuster control
  • connection between junction unit and headlamp adjustment motor
  • earths for headlamp adjustment motors and headlamp adjuster control

( See E3080 HEADLAMP AGLINMENT CORRECTOR).

Continue to Step 4

Connections broken

Restore the connections

4

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
