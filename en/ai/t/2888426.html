With the ignition key in the ON position, when the buttons on the doors are operated, the electric front windows do not work at all

Results of the tests

1

ELECTRIC WINDOWS ELECTRICAL CIRCUIT CHECK

All OK

Problems met

Operation

Check, in order:

  • electric windows fuse
  • electric windows control unit supply and earth
  • connection between electric windows control unit and switches
  • electric window switches earth

See E3050 ELECTRIC FRONT WINDOWS

Continue to Step 2

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections not correct

Restore the connections

2

ELECTRIC WINDOWS CONTROL UNIT CHECK

All OK

Problems met

Operation

Check that the electric windows control unit is working properlysee DESCRIPTION AND OPERATION: 5505 ELECTRICAL CIRCUIT FOR INSTRUMENTS/INDICATORS

Continue to Step 3

Control unit not working

Replace the electric windows control unit Op. 7005M40 front electric window system ecu - r+r following electrical wiring check
