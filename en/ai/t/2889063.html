Applies to: all engines; production: da 04/02 a 08/03

Description

The integrated services electronic control unit manages the operation of the boot lock release actuator on the command of:

  • from the inside, through the special button located next to the driver's seat;
  • from the outside, via the key and the rear lock

The command is only given if the vehicle is parked (i.e. with a speed signal below 4 km/h).

If the doors are locked, the command is possible only from inside and with the key ON. if the doors are released (open), the command can be given from outside or inside.
