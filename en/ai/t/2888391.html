Applies to: all engines; all production periods

With the ignition key ON, the speedometer does not work or works irregularly

Results of the tests

1

CHECK SPEEDOMETER ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • connection between speedometer and instrument
  • speedometer sensor power supply from the instrument
  • speedometer sensor earth

( See E4010 INSTRUMENT PANEL).

Continue to Step 2

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

Connections broken

Restore the connections

2

CHECK SPEEDOMETER SENSOR

All OK

Problems met

Operation

Check the operation of the speedometer sensor

Continue to Step 3

Sensor not working

Replace the speedometer sensor Op. 2180A36 milometer control sensor on gearbox - r + r

3

CHECK INSTRUMENT

All OK

Problems met

Operation

Check the operation of the instrument and the speedometer in particular see DESCRIPTION AND OPERATION: 5560 INSTRUMENT PANEL

Continue to Step 4

Instrument not working

Change the instrument Op. 5560B10 analogue control panel - r+r

4

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
