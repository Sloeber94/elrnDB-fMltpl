Applies to: all engines; all production periods

When the alarm is operated the volumetric surveillance does not work

tt is possible to exclude volumetric surveillance from system operation (5580E anti-theft device).

Results of the tests

1

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check, in order:

  • no faults in the alarm control unit
  • no faults in the alarm receiver

Continue to Step 2

Error detected in the control unit or receiver

Continue according to the instructions for the diagnostic equipment

Dialogue failure for diagnostic equipment between the control unit and the receiver

Restore the connection between the control unit and the diagnostic connector ( See E7015 ALARM).

2

CHECK VOLUMETRIC SENSORS

All OK

Problems met

Operation

Check, in order:

  • operation of volumetric sensors
  • connections between sensors and alarm control unit

See E7015 ALARM).

Continue to Step 3

Sensor faulty

Replace sensor Op. 5580E22 Anti-theft device VOLUMETRIC SENSORS - R.R. after checking electrical circuit.

Connections broken

Restore the connections

3

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
