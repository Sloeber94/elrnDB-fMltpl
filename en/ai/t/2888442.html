Applies to: all engines; all production periods

When the central locking is operated using the remote control the doors do not open / close at all (on the other hand, they open perfectly using the key)

Results of the tests

0

PRELIMINARY CHECKS

All OK

Problems met

Operation

Check the charge of the remote control battery incorporated in the key

Continue to Step 1

Remote control battery charge low

Replace the remote control battery

1

CHECK CENTRAL LOCKING ELECTRICAL CIRCUIT

All OK

Problems met

Operation

Check, in order:

  • the remote control receiver fuses
  • the remote control receiver supply and earth
  • the connection between the central locking control unit and the remote control receiver

See E3040 CENTRAL LOCKING

Continue to Step 2

Connections not correct

Restore the connections

Component defective

Replace the component involved (if a fuse is involved, search for the cause of the problem)

2

CHECK WITH DIAGNOSTIC EQUIPMENT

All OK

Problems met

Operation

Connect the diagnostic equipment (Examiner or other instruments) to the diagnostic socket

Check that there are no faults in the remote control receiver.

Continue to Step 3

Error detected in the receiver

Continue according to the instructions for the diagnostic equipment

Receiver not working

Replace the receiver Op. 5580E30 receiver for car alarm remote control - r r

Dialogue failure for diagnostic equipment between the control unit and the receiver

Restore the connecting serial line between the remote control receiver and the diagnostic connector ( See E3040 CENTRAL LOCKING)

3

CHECKING CORRECT OPERATION

All OK

Problems met

Operation

Check that the fault is no longer present

End of diagnosis

Fault persists

Search for the fault starting from another symptom'
