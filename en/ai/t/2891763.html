5010B09 PURIFYING FILTER (ANTIPOLLEN) FILTER ELEMENT - REPLACE

Removing

Refitting

The condition of the filter should be checked once a year and it should preferably be replaced before the hot weather.

1. Remove the filter cover.

2. Undo the bolt.

3. Remove the cover.

4. Extract the filter element.

Applies to: all engines; production: fino a 05/99, da 09/03, da 06/99 a 03/02, da 04/02 a 08/03, fino a 05/04

Refitting

Removing

Check that the filter element is not damaged or clogged.

1. Position the filter element (1a).

The reference arrows (1b) should be facing towards the passenger compartment.

2. Position the cover.

3. Tighten the bolt.

4. Fit the filter cover.

Applies to: all engines; production: da 06/04

Removing

Refitting

The condition of the filter should be checked at least once a year and it should preferably be replaced at the beginning of the hot season.

1. Release the filter cover.

2. Undo the bolts.

3. Remove the cover.

4. Extract the filter element.

Applies to: all engines; production: da 06/04

Refitting

Removing

Check that the filter element is not damaged or blocked.

1. Position the filter element (1a).

The reference arrows (1b) should be facing the passenger compartment.

2. Position the cover.

3. Tighten the bolts.

4. Fit the filter cover.
